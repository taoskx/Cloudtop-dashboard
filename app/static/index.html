更新说明（v2.7.0）

v2.7.0 · 当前版本
2026-10-23
  • 全新叠放卡片：账号卡片改为 iPhone 后台式叠放呈现，全部账号一屏看完、页面不再滚动；鼠标悬停侧卡预览、点击切换到中间操作，滚轮/方向键/圆点也可切换，动画顺滑。
  • 新图标：程序图标更换为机器人新形象（窗口、任务栏与网页图标同步）。
v2.6.2
2026-10-23
  • 无闪刷新：后台数据改为静默增量同步，只更新变化的文字与状态，卡片不再每 5 秒整屏重画；状态呼吸点平滑呼吸，倒计时数字等宽不跳动。
v2.6.1
2026-10-23
  • 发信通道更换：解锁验证码改由 QQ 邮箱发送与接收，解决 Gmail 在部分网络下不可达的问题；使用方式不变。
v2.6.0
2026-10-23
  • 软件更名：正式更名为 Cloudtop Dashboard（程序文件 Cloudtop-Dashboard.exe），功能与数据与之前版本完全一致，原有 data 文件夹可直接沿用。
v2.5.1
2026-10-23
  • 发信配置内置：解锁验证码的发信通道已内置于软件，单个 exe 到任何电脑都可直接申请验证码，无需再逐台配置。
v2.5.0
2026-10-23
  • 邮箱验证码解锁：软件需作者授权使用——使用者填邮箱申请，验证码只发送到作者邮箱、由作者转交；输对一次即永久解锁本机应用，不再需要登录。
  • 安全规则：验证码 20 分钟内有效；连续输错 3 次锁定 1 小时，期间不可输码、不可再申请。
  • 作者设置：发信邮箱在解锁页「作者设置」中配置（Gmail + 应用专用密码），只保存在本机，不随软件代码分发。
v2.4.0
2026-10-23
  • 界面全面改版：三平台账号卡片统一尺寸、等宽等高，分组列表式排版，开关全局对齐。
  • 天翼任务与开关合并：每日任务进度与对应开关同行呈现，与功能开关同属「自动化开关」一栏，总分一目了然。
  • 卡片信息精简：隐藏设备 ID 等技术标识，监视区只保留状态与关键运行信息（上次保活 / 周期 / 距下次）。
  • Windows 绿色版：提供单文件 exe，免安装、双击即用，数据保存在 exe 旁的 data 文件夹。
v2.3.1
2026-09-28
  • 移动公众接入：三平台同台管理，独立登录与分层保活，支持开机 / 关机 / 重启。
  • 移动爱家 SCG 底座打通：经官方 CEM 通道恢复开机能力，全程使用账号自有凭据。
  • 自动开机守护：移动公众与 SCG 账号默认开启，只对确定关机的机器下发，10 分钟冷却。
  • 30 天免登录：勾选后重启不掉线，退出登录才失效。
  • 稳定性：Python 解释器真伪探测、侧车并发修复、日志降噪。
移动公众功能需要 Python 3 环境（绿色版已内嵌）；天翼云与移动爱家无需 Python。
